# 下载季集校验

在向下载器添加任务之前，读取种子内部视频文件的季集，并与本次订阅匹配的目标季集比较。
冲突时跳过当前资源，让 MoviePilot 保留缺集并继续尝试其他候选。

例如站点标题匹配为 `S01E50`，种子内文件名却是：

```text
The.Apothecary.Diaries.S03E02.The.Fire-Rat.Cloak.1080p.NF.WEB-DL.AAC2.0.H.264-VARYG.mkv
```

插件会在视频开始下载之前拦截这条资源。后续候选的内部文件正确识别为 `S01E50` 时，允许下载。

## 安装

支持 **MoviePilot >=2.15.6,<3**；本仓库只提供 V2 插件。

1. 在 MoviePilot 插件市场设置中添加本仓库地址：
   `https://github.com/z-henry/MoviePilot-Plugins`。
2. 刷新插件市场，安装“下载季集校验”。
3. 开启“启用下载季集校验”。
4. 建议保留默认开启的“仅检查订阅下载”和“无法校验时跳过资源”。

插件默认关闭，安装后需要启用。关闭启用开关即可停止拦截。

1.1.0 增加 `libtorrent==2.0.11` 依赖，由 MP 在插件安装／更新时安装。
支持 Python 3.11／3.12 常见 Linux x86_64 和 ARM64 环境；没有可用依赖时，
磁力资源会归为“无法校验”，不影响普通种子地址的校验。

## 磁力链校验

只检查 MP 提供的资源，不抓取站点详情页，不在插件中维护网站适配规则：

- `.torrent` 地址或需要解析的下载地址：仍调用 MP 的获取逻辑，沿用其认证、代理和缓存。
- 磁力链（也包括 MP 解析下载地址后返回的磁力链）：通过 Tracker／DHT 和 BT 元数据协议
  获取内部文件列表，核对元数据哈希，再沿用同一套季集识别规则。
- 只获取种子元数据，不请求视频分块，不向现有下载器创建临时任务。
- 每条资源最多等待 15 秒；每次订阅搜索累计获取元数据最多等待 30 秒。
  获取成功较快时，剩余预算可以用于下一个候选；普通种子下载不占这项预算。
- 最多并发 2 个独立校验进程，每个最多连接 12 个节点；超时结束进程并清理临时目录。
- 元数据按哈希缓存在内存中，成功缓存 24 小时，失败缓存 5 分钟；
  最多 128 条、16 MiB，单个元数据最多 2 MiB。插件重载后缓存清空。
  缓存不保存“允许／拦截”结论，因此修改订阅识别词后会重新判断。
- 如果该站点启用代理，磁力元数据连接目前支持 SOCKS5；仅有 HTTP 代理时会归为
  “无法校验”，不会绕过代理改用直连。普通种子地址仍使用 MP 支持的代理。

冷门磁力没有可用节点时可能拿不到元数据。超时、依赖不可用等情况均遵守
“无法校验时跳过资源”开关：开启则跳过；关闭则放行。明确季集冲突始终拦截。

## 校验规则

| 场景 | 处理方式 |
| --- | --- |
| 订阅下载的单集资源 | 内部正片季集必须与候选目标一致 |
| 标注集数范围的合集 | 检查所有内部正片的季集集合，缺集或额外集均拦截 |
| 主程序选择部分集下载 | 必须覆盖选中集，允许同季其他集；其他季的视频会被拦截 |
| 未标注集数的整季资源 | 使用订阅开始集和总集数检查覆盖，允许同季较早的集 |
| 配置了订阅识别词 | 使用与整理相同的识别词解析；已正确配置的季集偏移不会被误拦截 |
| 没有订阅识别词 | 保留 MoviePilot 全局识别词回退 |
| 文件夹带季号 | 使用 `MetaInfoPath`，保留文件继承父目录季号的行为 |
| 样片与字幕 | 忽略常规 sample/trailer 视频和非视频文件 |
| 手动下载、电影、音乐 | 默认不检查；关闭“仅检查订阅下载”后可检查手动下载的电视剧 |

插件核对的是识别后的季集，不要求网页标题与文件名文本完全相同。
如果文件 `S03E02` 已通过订阅识别词正确映射为 `S01E50`，会允许下载。

## 无法校验的资源

“无法校验时跳过资源”默认开启，包括：

- 磁力元数据获取失败、超时、依赖不可用、代理不支持，或者本次搜索等待预算用完。
- `.torrent` 读取失败、内容无法解析。
- 没有可识别的正片视频，或正片缺少可确定的季集。
- 整季候选没有可靠的开始集／总集数范围。
- 多季合集：本版不猜测单季订阅与多季包之间的映射。
- 无法读取本次订阅及其识别词。

关闭该选项会放行这些无法判断的资源，并记录“放行（未校验）”。**明确季集冲突仍然会拦截。**

## 查看记录

插件详情页保存最近 50 条冲突或无法校验的记录，包含站点、标题、原因和跳过／放行结果。
主程序日志也会记录检查结果。不主动发送通知，避免每次匹配产生消息。

拦截后不会把该集记为已下载。当前批次还有其他候选时继续尝试；全部候选被拒绝时保留缺集，
等待后续订阅刷新或搜索。下次搜索可能再次检查同一资源。

## 实现与限制

- 使用官方 `ChainEventType.ResourceDownload` 事件，通过 `cancel=True` 否决本次资源。
- 不修改或包装主程序方法，不直接修改订阅缺集记录，不自行添加下载任务。
- 使用宿主 `DownloadChain.download_torrent` 获取种子元数据，复用 Cookie、代理、
  间接下载地址处理和种子缓存。普通 URL 通常复用缓存，短时凭证或换票地址可能增加站点请求。
- 事件不携带主程序已经读取的种子字节，因此无法保证所有地址只请求一次。
- 只核对季集，不验证视频实际内容，也不校验相同季集的文件是否真的来自目标剧。
- 不处理已经下载或已经整理的文件。
- 事件取消后的失败／冷却和下次重搜时机由 MoviePilot 控制。
- 磁力校验依赖 `libtorrent==2.0.11`。HTTP 种子路径不加载此依赖。

## 开发验证

在仓库根目录执行：

```bash
python3 -m venv /tmp/episodeguard-tests
/tmp/episodeguard-tests/bin/pip install -r plugins.v2/episodeguard/requirements.txt
/tmp/episodeguard-tests/bin/python -m unittest discover -s tests -p 'test_episodeguard*.py' -v
```

测试使用模拟应用边界，不接触实际站点或下载器。若 `/tmp/mpv2-download.py` 存在对应的 V2
主程序源码，还会直接执行其中的候选循环，验证第一候选被拦截后继续处理第二候选。
协议测试使用本机模拟 BT 节点，关闭 DHT，不访问外部站点或下载器；验证取得哈希匹配的
元数据、未发送视频分块请求、未创建视频文件。未安装 libtorrent 时跳过原生协议测试。

在有 V2 容器的开发机器上，可进一步运行：

```bash
python3 scripts/episodeguard_native_probe.py --container moviepilot-v2 --sudo
```

验证脚本只在内存中调用容器实际的种子解析器、识别词处理器和 Rust 路径识别器，
通过合成种子检查季集冲突、正确单集、偏移规则、父目录季号以及字幕／样片。
应用边界被模拟，不访问站点，不写服务文件或设置，也不产生实际下载任务。
